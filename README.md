# Image Converter Project

##Description
A simple Windows Forms application for converting image formats with multi-file selection support.

## Features
- Select one or multiple image files.
- Convert images to various formats: JPG, PNG, BMP, GIF, TIFF.
- Save converted images to a desired location.

## How to Use
1. Run the application.
2. Click the image area to select images.
3. Choose the output format from the dropdown.
4. Press the 'Convert' button to save.

## Tools & Libraries
- Visual Studio
- C#
- Windows Forms

## Design
The interface design can be created in Adobe XD and integrated into the project via HTML, CSS, and JavaScript export.
